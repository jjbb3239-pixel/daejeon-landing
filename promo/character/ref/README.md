## 사용 순서

```
[N-0] 생성 시 첨부 : A1 (필수) + A2 + B1
        ↓ 정면 얼굴 확정
[N-1]~[N-6] 생성 시 첨부 : 확정된 정면 얼굴 1장 + 해당 부위 레퍼런스
        예) [N-3] 전신 정면 → 확정 얼굴 + C1 + C3 + B2
```

A1 을 첨부하지 않고 텍스트만으로 생성하면 다른 사람이 나온다. **A1 은 매번 첨부한다.**
