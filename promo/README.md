## 만드는 순서

```bash
python build_cards.py     # 문구·레이아웃 -> *.dc.html 13장
python render.py          # -> jpg/*.jpg   (잘림 검사 포함)
python to_svg.py          # -> svg/{A안,B안,C안}.svg
```

`build_cards.py` **하나만 고치면 된다.** 13장이 같은 껍데기(`shell()`)를 쓴다.
`render.py` 는 각 카드의 내용 높이를 실측해 프레임(1158px)을 넘으면 `OVERFLOW` 로 알려준다.

### Figma 로 넘기기

`to_svg.py` 는 브라우저에서 렌더한 실측 좌표를 읽어 진짜 도형·`<text>` 로 다시 그린다.
HTML 을 그대로 감싸는 방식(`foreignObject`)은 Figma 가 못 읽기 때문이다.
`svg/*.svg` 를 Figma 에 드래그하면 컷마다 이름이 붙은 편집 가능한 레이어로 들어온다.

알고 쓸 한계 :

- 배경 도트 텍스처는 빠진다. 단색 바탕만 남는다.
- 줄바꿈이 렌더된 상태로 굳는다. Figma 에서 글을 늘리면 다시 흐르지 않는다.
- 제목의 하드섀도우는 Figma 에서 **드롭섀도우 효과**로 바꿔뒀다 (radius 0). SVG 자체에는
  그림자용 텍스트 사본이 한 장 더 들어 있으니, 새로 반입할 때 사본을 다시 정리해야 한다.

## 사진 3장 — 게시 전 반드시 처리 (2026-09-02 확인)

`spot100x100.kr` 을 직접 확인한 결과 :

- 운영 주체는 **대전시가 아니라 한국관광공사**다. (사이트 제목 「대한민국 명소발굴 100×100 | 한국관광공사」)
- **이용약관 · 저작권 표시 · 공공누리 유형이 사이트에 전혀 없다.** 푸터 링크는
  개인정보처리방침(knto.or.kr) 하나뿐이다.

즉 **재이용 범위를 사이트만으로는 확인할 수 없다.** 한국관광공사 사진자료는 공공누리
제4유형(출처표시 + 상업적 이용금지 + 변형금지)인 경우가 흔한데, 그렇다면 우리 카드뉴스는
크롭·오버레이·SNS 게시로 두 조건을 모두 건드린다.

**할 일 : 한국관광공사에 이용 범위를 문의한다.** 답이 오기 전까지 선택지 두 개 —

| | 방법 | 영향 |
|---|---|---|
| A | 사진 3장을 쓰는 카드(B1 · B2 · A2)를 **무지 배경으로 전환** | `build_cards.py` 에서 `photo=` → `ground="ivory"` 로 바꾸면 끝. 표지의 힘은 줄어든다 |
| B | 직접 촬영본이나 공공누리 제1유형 사진으로 **교체** | 식장산 사진처럼(대전광역시 동구 · 제1유형) 출처가 확실한 것으로 |

사진 없는 카드 10장(B3 · B4 · A1 · A3 · A4 · A5 · C1~C4)은 **지금 그대로 게시 가능**하다.
공식 축제 포스터와 꿈돌이·꿈씨패밀리만 쓴다.
