### ⚠️ 기관명은 쓰지 않는다

교육 과정의 실습물이지 기관이 만든 페이지가 아니다. 「고용노동부」를 문구에 넣으면
**공공기관 공식 페이지로 오인될 수 있다.** 대전시 공식 캐릭터(꿈돌이)를 이미 쓰고 있어
오인 소지가 더 크다. 랜딩페이지 푸터와 같은 표현으로 통일한다.

```
[X]  고용노동부 마케팅 교육 팀플로 만든 대전 여행 페이지
[O]  마케팅 교육 과정 팀 프로젝트로 만든 비상업 페이지입니다
```

### ⚠️ 프로필 이미지로 꿈돌이를 쓰지 않는다

카드뉴스 **안에서** 쓰는 것과 **계정의 얼굴**로 쓰는 것은 다르다. 계정 아이콘이 꿈돌이면
대전시 공식 계정으로 읽힌다. 승차권 모티프나 카드뉴스 표지 크롭을 쓴다.

신계정이 첫날부터 링크 달린 홍보 게시물만 올리면 **스팸 필터에 걸려 도달이 0에 가깝다.**

```
1일차   계정 개설 → 프로필 완성 (이름 · 소개 · 링크 · 이미지)
2~3일차 홍보 아닌 게시물 2~3개  (대전 사진 한 장 + 한 줄 같은 것)
4일차   ★ 메인 게시물 (아래 초안)
```

## 5. 커뮤니티 — 사이트 정해지면 이 골격으로

미정이라 본문은 안 썼다. 확정 후 이 틀에 채운다.

```
제목    정보를 명시한다. 낚시보다 명시가 낫다
          [O] 대전 혼자 여행 코스 정리해봤습니다 (사진 · 도보시간 포함)
          [X] 대전 여행 이거 모르면 손해입니다

본문    ① 왜 만들었나 한 단락
        ② 정보 전부 — 기분 4종 + 각 코스 + 도보시간
        ③ 사진 여러 장 (카드뉴스 JPEG 그대로)
        ④ 맨 아래 한 줄로 링크
        ⑤ 「마케팅 교육 과정 팀 프로젝트 · 비상업」 명시

원칙    링크를 지워도 글이 성립해야 한다.
        본문이 링크 유도용 미끼면 커뮤니티는 바로 알아본다.
```

### 게시 전 확인

- 해당 게시판의 **홍보 · 링크 금지 규정**
- 계정 활동 이력 (신계정 + 링크 = 스팸 처리)
- **여러 계정으로 나눠 올리지 않는다.** 어뷰징이고, 걸리면 프로젝트가 끝난다
