```

② 지금 가장 큰 누수는 카피가 아니라 로드 4.2초다. 여기서 CVR 이 직접 깎인다.

④ 그래서 전략은 하나뿐 — 의향 있는 유입만 늘린다.
```

우선순위는 이 순서다. **카피는 3번째다.**

| LCP 요소 | `DIV.hero-bg-word` (텍스트) | 폰트·JS 대기가 원인 |
| DOMContentLoaded | 2,077 ms | |

**첫 화면 설계는 좋다.** CTA 가 크고, 플로팅 버튼이 하나 더 있고, 히어로 카피가
게시물 약속과 일치한다. 문제는 **이 화면이 4.2초 뒤에 뜬다는 것**이다.

### 전송량 내역과 개선 여력

| | 현재 | 개선 후 | 절감 |
|---|---|---|---|
| PNG 6종 (꿈돌이 · 꿈씨패밀리) | 1,180 KB | WebP 234 KB | **946 KB** |
| 폰트 woff2 5종 | 886 KB (첫 화면에 4종 = 713 KB) | 3종으로 줄이면 531 KB | 355 KB |
| JS | 259 KB | — | — |

**PNG → WebP 하나로 946KB, 전체의 52% 가 사라진다.** 4G 1.6Mbps 에서
946KB = 4.7초 분량의 대역폭이다. 이게 LCP 를 잡고 있는 주범이다.

### 왜 이게 CVR 문제인가

```
세션은 페이지가 열리는 순간 잡힌다.
전환은 4.2초를 기다린 사람만 만든다.

→ 로드가 느리면 분모는 늘고 분자는 안 늘어 CVR 이 직접 깎인다.
→ 로드 개선은 카피와 무관하게 CVR 을 올리는 유일한 기술 레버다.
```

## 3. CVR 2% 산수 — 쉬운가 어려운가

우리 전환은 **가입 없음 · 비용 없음 · 4탭 · 30초.** 마찰이 거의 없다.
그래서 의향 있는 유입의 완료율은 높게 잡을 수 있다.

유입을 둘로 나눈다 — **q** = 의향 유입(대전 여행에 관심), **j** = 호기심 클릭.

```
전체 CVR = (q·Cq + j·Cj) / (q + j) ≥ 0.02
```

### 시나리오 A — 로드를 고친 경우 (Cq 12%, Cj 0.5%)

```
0.12q + 0.005j ≥ 0.02(q + j)
0.10q ≥ 0.015j
j ≤ 6.7q
```
→ **호기심 유입이 의향 유입의 6.7배까지 괜찮다.** 여유가 크다.

### 시나리오 B — 로드를 안 고친 경우 (Cq 4%, Cj 0.5%)

```
0.04q + 0.005j ≥ 0.02(q + j)
0.02q ≥ 0.015j
j ≤ 1.33q
```
→ **호기심 유입이 의향 유입의 1.33배만 넘어도 목표 미달.**

> **로드 개선이 CVR 안전마진을 5배 늘린다.** 이건 추정이 아니라 산수다.
> 그래서 9/3 까지 이미지 최적화를 끝내는 것이 캠페인 1순위다.

## 4. 세션 추정 — 진짜 위험은 여기 있다

개인 계정 4명 · 팔로워 미지. 보수적으로 잡으면 :

| 채널 | 게시 횟수 | 세션/회 | 7일 합계 |
|---|---|---|---|
| X (4명) | 3회 × 4명 | 3~10 | 36~120 |
| 스레드 (4명) | 3회 × 4명 | 5~30 | 60~360 |
| 아이보스 | 1회 | 20~200 | 20~200 |
| 오픈채팅 | 1~2회 | 5~75 | 5~150 |
| 릴스 2편 | 2회 | 10~100 | 20~200 |
| | | **합계** | **140 ~ 1,030** |

### 여기서 나오는 역설

```
세션 150  →  CVR 2% = 전환 3개   → 팀원이 직접 해도 채워진다. 쉽다
세션 1000 →  CVR 2% = 전환 20개  → 진짜 유입이 필요하다. 어렵다
```

**세션이 적으면 CVR 2% 는 자동 달성된다. 세션이 늘수록 어려워진다.**
그리고 전환 절대수가 한 자리면 CVR 은 통계가 아니라 운이다 — 한두 명이 지표를 흔든다.

### 그래서 목표를 이렇게 재정의한다

> **세션 500 이상 + CVR 2% 이상.**
> 세션 150 에 CVR 5% 를 만드는 건 성과가 아니라 표본 부족이다.
> CMO 보고에서 방어되지 않는다.

## 5. 메시지 정렬 — 기획의 핵심

전환은 `mood_test_complete` 다. **테스트를 하게 만드는 글**이어야 한다.

```
게시물이 약속하는 행동  =  랜딩 첫 화면  =  전환 액션
        셋이 같아야 한다
```

### ⚠️ 내가 앞서 쓴 초안에 CVR 킬러가 있었다

```
[내 초안 트윗 3]
"맛집은 블루리본만 골랐고 메뉴·가격·대전역에서 도보 몇 분인지까지 적어놨다"
```

이건 **정보를 약속한다.** 이걸 보고 온 사람은 맛집 섹션만 읽고 나간다.
세션은 늘고 전환은 안 늘어 **CVR 을 직접 깎는다.** 폐기한다.

정보성 문구는 아이보스처럼 신뢰가 필요한 곳에만 쓰고,
X · 스레드에서는 **전환 행동만 약속한다.**

### 카피 3원칙

| | 원칙 | 적용 |
|---|---|---|
| 1 | **정보를 약속하지 않는다** | "코스 정리했다" ✕ → "당신이 어느 쪽인지 나온다" ○ |
| 2 | **호기심 갭을 만든다** | 4가지를 보여주되 결과는 안 알려준다 |
| 3 | **마찰을 먼저 없앤다** | "질문 4개 · 30초 · 가입 없음" 을 매번 반복 |

3원칙을 다 만족하는 최소 문장 :

> **"대전 갈 때 당신은 넷 중 어느 쪽인가요. 질문 4개, 30초."**

### 중단 기준 (미리 정한다. 감으로 판단하지 않는다)

| 조건 | 조치 |

### 9/9 중간 데이터 공개는 그 자체가 소재다

앞선 5일 숫자를 게시물로 쓴다. "N명이 돌렸고 가장 많이 나온 결과는 X" —
숫자가 들어가면 홍보가 아니라 **관찰**이 되어 확산된다. 비용 0 의 2차 도달.

## 9. CMO 보고에서 방어할 논리

```
"세션 N, CVR M% 를 달성했다" 로 끝내면 운으로 보인다.

이렇게 보고한다 —
  ① 시작 전 진단에서 LCP 4.2초를 발견해 946KB 를 줄였다  (원인 규명)
  ② 채널을 도달용과 전환용으로 분리해 운영했다          (전략)
  ③ 가설 4개를 세워 utm_content 로 분리 측정했다         (검증 설계)
  ④ 9/7 중간 점검에서 CVR 1% 미달 채널을 끊었다          (운영 판단)
  ⑤ 결과 : 세션 N · CVR M%                              (성과)

성과는 ⑤ 한 줄이지만, 방어되는 건 ①~④ 다.
```
